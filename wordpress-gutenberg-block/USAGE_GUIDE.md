# 使用指南 / Usage Guide

## 繁體中文使用說明

### 區塊 1: 產品展示 (Product Showcase)

這個區塊讓您以網格方式展示寵物產品。

#### 使用步驟：

1. **新增區塊**
   - 在編輯器中點擊「+」按鈕
   - 搜尋「Product Showcase」或「產品展示」
   - 點擊新增

2. **編輯標題和描述**
   - 直接在區塊上點擊標題和描述進行編輯

3. **新增產品**
   - 點擊右側面板的「Inspector Controls」
   - 在「Product Settings」中編輯每個產品：
     - **產品名稱**: 輸入產品名稱
     - **描述**: 輸入產品描述
     - **圖片**: 點擊「Select Image」選擇圖片
   - 點擊「Add Product」新增更多產品
   - 點擊「Remove Product」刪除不需要的產品

4. **儲存**
   - 點擊「更新」或「發布」按鈕

#### 範例場景：
```
標題: 我們的 OEM/ODM 產品線
描述: 專業製造高品質寵物用品

產品 1:
- 名稱: 寵物高架床
- 描述: 耐用舒適的寵物高架床，提供最佳支撐
- 圖片: [上傳產品圖片]

產品 2:
- 名稱: 狗狗胸背帶
- 描述: 優質材料製作，確保寵物安全舒適
- 圖片: [上傳產品圖片]
```

### 區塊 2: 服務特色 (Service Features)

展示您的 OEM/ODM 製造服務特色。

#### 使用步驟：

1. **新增區塊**
   - 搜尋「Service Features」或「服務特色」
   - 點擊新增

2. **編輯標題**
   - 直接點擊標題進行編輯

3. **設定服務特色**
   - 在右側面板的「Feature Settings」中：
     - **圖示**: 輸入 emoji 符號（如 🏭、🎨、🏷️）
     - **標題**: 輸入服務名稱
     - **描述**: 輸入服務說明
   - 點擊「Add Feature」新增更多特色
   - 點擊「Remove Feature」刪除特色

#### 範例場景：
```
標題: 我們的專業服務

特色 1:
- 圖示: 🏭
- 標題: OEM 代工製造
- 描述: 提供專業的 OEM 代工製造服務

特色 2:
- 圖示: 🎨
- 標題: ODM 客製設計
- 描述: 從設計到生產的完整 ODM 解決方案

特色 3:
- 圖示: 🏷️
- 標題: 自有品牌
- 描述: 協助建立您的專屬寵物用品品牌
```

### 區塊 3: 行動呼籲 (CTA Section)

吸引訪客採取行動的大型橫幅區塊。

#### 使用步驟：

1. **新增區塊**
   - 搜尋「CTA Section」
   - 點擊新增

2. **編輯內容**
   - 直接點擊標題和描述進行編輯

3. **設定按鈕和顏色**
   - 在右側面板的「CTA Settings」中：
     - **Button Text**: 按鈕文字（如「立即詢價」）
     - **Button URL**: 連結網址（如 #contact 或完整 URL）
     - **Background Color**: 背景顏色（使用顏色選擇器）
     - **Text Color**: 文字顏色

4. **設定對齊方式**（可選）
   - 在工具列選擇「Wide width」或「Full width」

#### 範例場景：
```
標題: 準備開始您的專案了嗎？
描述: 立即聯繫我們，獲取 OEM/ODM 寵物用品製造解決方案

按鈕文字: 立即詢價
按鈕連結: /contact
背景顏色: #1e40af (深藍色)
文字顏色: #ffffff (白色)
```

## English Usage Guide

### Block 1: Product Showcase

Display your pet products in a beautiful grid layout.

#### How to Use:

1. **Add Block**
   - Click the "+" button in the editor
   - Search for "Product Showcase"
   - Click to add

2. **Edit Title and Description**
   - Click directly on the title and description to edit

3. **Add Products**
   - Click "Inspector Controls" in the right panel
   - In "Product Settings", edit each product:
     - **Product Name**: Enter product name
     - **Description**: Enter product description
     - **Image**: Click "Select Image" to choose image
   - Click "Add Product" to add more products
   - Click "Remove Product" to delete unwanted products

4. **Save**
   - Click "Update" or "Publish"

---

### Block 2: Service Features

Showcase your OEM/ODM manufacturing service features.

#### How to Use:

1. **Add Block**
   - Search for "Service Features"
   - Click to add

2. **Edit Title**
   - Click the title directly to edit

3. **Configure Features**
   - In the right panel's "Feature Settings":
     - **Icon**: Enter emoji symbol (e.g., 🏭, 🎨, 🏷️)
     - **Title**: Enter service name
     - **Description**: Enter service description
   - Click "Add Feature" to add more features
   - Click "Remove Feature" to delete features

---

### Block 3: CTA Section

Eye-catching banner block to encourage visitor actions.

#### How to Use:

1. **Add Block**
   - Search for "CTA Section"
   - Click to add

2. **Edit Content**
   - Click the title and description directly to edit

3. **Configure Button and Colors**
   - In the right panel's "CTA Settings":
     - **Button Text**: Button text (e.g., "Get a Quote")
     - **Button URL**: Link URL (e.g., #contact or full URL)
     - **Background Color**: Use color picker
     - **Text Color**: Use color picker

4. **Set Alignment** (Optional)
   - Select "Wide width" or "Full width" from toolbar

---

## 提示和技巧 / Tips and Tricks

### 繁體中文

1. **色彩搭配**: 使用品牌色彩以保持一致性
2. **圖片優化**: 上傳前先壓縮圖片以提升載入速度
3. **響應式設計**: 所有區塊都自動適應手機版面
4. **複製區塊**: 使用「複製」功能快速建立相似區塊

### English

1. **Color Matching**: Use brand colors for consistency
2. **Image Optimization**: Compress images before upload for faster loading
3. **Responsive Design**: All blocks automatically adapt to mobile screens
4. **Duplicate Blocks**: Use "Duplicate" feature to quickly create similar blocks
